## 💎 Comandos habilitados

| Comando                            | Para qué sirve                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `/register <clave> <clave>`        | Crea la cuenta la primera vez. La clave se escribe dos veces para confirmarla. |
| `/login <clave>`                   | Inicia sesión en ingresos posteriores.                                         |
| `/changepassword <actual> <nueva>` | Cambia la contraseña (solo si ya iniciaste sesión).                            |

::: info
**no debes** escribir los símbolos `<` `>`.
:::
## 🛼 Ejemplos

```
/register mesti12345 mesti12345
/login mesti12345
/changepassword mesti12345 essentials12345
```
